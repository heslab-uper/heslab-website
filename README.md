# HESLab Website

Situs resmi Hydro-Environmental Systems Laboratory (HESLab),
Program Studi Teknik Sipil, Universitas Pertamina.

Repo ini HANYA berisi HTML hasil build. Seluruh kode generator berada
di folder lokal `heslab-website-src` (tidak dipublikasikan). Jangan
mengedit file di repo ini secara langsung — perubahan akan tertimpa
saat deploy berikutnya.

Tayang di: https://heslab-uper.github.io/heslab-website/
