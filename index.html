Survei Hidrometri Sungai Angke dan Sungai Bekasi

15 November 2026

Pengukuran debit Sungai Angke (Jembatan Angke, Tangerang) dan Sungai Bekasi dengan current meter, bagian dari penelitian DIKTI Integrasi Data Satelit, Pemodelan Hidrologi, dan Machine Learning untuk Peringatan Dini Banjir JABODETABEK. Debit terukur 3,9 m³/dt di Angke dan 16,8 m³/dt di Bekasi. Data ini dipakai untuk memperkirakan kapasitas penampang sungai sebagai ambang peringatan dini banjir.

Survei Debit Sungai

18 Juli 2026

Survei debit sesaat dilakukan sebagai bagian dari penelitian DIKTI -Integrasi Data Satelit, Pemodelan Hidrologi, dan Machine Learning untuk Peringatan Dini Banjir JABODETABEK-. Data yang diperoleh dimanfaatkan untuk kalibrasi model hujan-limpasan dan peningkatan keandalan prediksi banjir.
